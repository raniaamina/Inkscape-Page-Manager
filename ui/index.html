INK Page Manager for Inkscape

Page Manager v1.0.0

Ekstensi manajemen multi-halaman Inkscape profesional dengan antarmuka menu yang intuitif dan visual, WYSIWYG real-time canvas, penomoran halaman cerdas, header & footer, watermark, margin guides, dan susunan otomatis.

Fitur Utama

  • Pengurutan & CRUD halaman visual realtime
  • Susunan otomatis: Grid, Baris, Kolom, Spreads
  • Nomor halaman (Arab, Romawi, Alfabet + Kustom)
  • Header & Footer multiline, logo gambar & garis pembatas
  • Watermark teks dan gambar cap dengan opasitas & rotasi
  • Template ukuran kustom tersimpan permanen
  • Dukungan tema Gelap, Terang, dan pilihan backend window

Pintasan Keyboard

  • Enter : Tambah halaman baru
  • Del / Backspace : Hapus halaman
  • Ctrl + Klik : Pilih banyak halaman
  • Scroll : Zoom in / out kanvas
  • Drag : Geser / pan viewport kanvas
